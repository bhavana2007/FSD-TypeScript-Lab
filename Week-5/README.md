# Week 5 - Creating Web Server Using Express

## Objective
Create a basic web server using Express.js and implement routing, route parameters, query parameters, and dynamic URLs.

## Lab Experiments
1. Setup Express server
2. Define basic routes
3. Work with route parameters
4. Use query parameters
5. Build dynamic URLs

## Run
```bash
npm install
npm run dev
```

Server: `http://localhost:3000`

## Test URLs
- `/`
- `/about`
- `/users/101`
- `/search?keyword=typescript&page=2`
- `/products/laptop/501`
