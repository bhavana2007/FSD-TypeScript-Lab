# Week 5 - Creating Web Server Using Express

## Objective
To introduce server-side development using ExpressJS and implement routing mechanisms.

## Experiments
1. Setup Express server
2. Define basic routes
3. Work with route parameters
4. Use query parameters
5. Build dynamic URLs

## Run
Install Express:

```bash
npm install express
```

Run any experiment:

```bash
node 1_setup_express_server.js
```
