# Week 7 - Server-Side Rendering

## Objective
Implement server-side rendering using a template engine and build interactive web pages that handle dynamic data, form input and basic validation.

## Experiments
1. Configure EJS template engine
2. Render dynamic values
3. Accept form inputs
4. Perform basic validation

## Technology
- Node.js
- Express.js
- EJS

## Run
From the `Week-7` directory, install dependencies:

```bash
npm install express ejs
```

Run the experiments separately:

```bash
node 1_ejs_template.js
node 2_dynamic_values.js
node 3_form_validation.js
```

Then open the URL printed in the terminal.

- Experiment 1: `http://localhost:3002/`
- Experiment 2: `http://localhost:3003/students`
- Experiments 3 & 4: `http://localhost:3004/register`

The examples use different ports so all three servers can be demonstrated independently.
